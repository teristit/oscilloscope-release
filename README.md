# Осциллограф

WPF-приложение для отображения нескольких синусоид на графике во времени.

## Запуск

Нужен Windows и .NET 10.0 или новее.

```
dotnet run --project oscilloscope
```

Или открыть `oscilloscope.slnx` в Visual Studio и запустить.

## Что умеет

- Добавлять/удалять синусоиды, редактировать имя и цвет (палитра из 8 цветов)
- Менять амплитуду, частоту и фазу каждой синусоиды
- Фаза задаётся в градусах или радианах (переключатель)
- Прятать/показывать отдельные синусоиды
- Показывать сумму всех видимых сигналов
- Анимация: сигнал «бежит» по временной шкале, есть пауза/продолжение и сброс времени
- Настраиваемый диапазон времени на графике
- Автомасштабирование по вертикали либо фиксированный масштаб по максимальной амплитуде
- Сохранять/загружать конфигурацию в JSON

## Технологии

- WPF (.NET 10)
- [ScottPlot 5](https://scottplot.net/) — отрисовка графика
- [CommunityToolkit.Mvvm](https://learn.microsoft.com/dotnet/communitytoolkit/mvvm/) — MVVM-инфраструктура

## Структура проекта

- `oscilloscope/MainWindow.xaml` - интерфейс
- `oscilloscope/MainWindow.xaml.cs` - логика обновления графика и таймер анимации
- `oscilloscope/ViewModel/MainViewModel.cs` - состояние приложения, сохранение/загрузка JSON
- `oscilloscope/ViewModel/SineWaveModel.cs` - модель синусоиды и палитра цветов
- `oscilloscope/Converters.cs` - конвертеры для binding
