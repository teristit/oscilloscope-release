# Осциллограф

Программа для отображения нескольких синусоид на графике.

## Запуск

Нужен .NET 10.0 или новее.

```
dotnet run --project oscilloscope
```

Или открыть `oscilloscope.sln` в Visual Studio и запустить.

## Что умеет

- Добавлять/удалять синусоиды
- Менять амплитуду, частоту, фазу и цвет
- Прятать/показывать отдельные синусоиды
- Показывать сумму всех сигналов
- Сохранять/загружать в JSON

## Структура проекта

- `ViewModel/` - MVVM ViewModels
- `MainWindow.xaml` - интерфейс
- `Converters.cs` - конвертеры для binding
